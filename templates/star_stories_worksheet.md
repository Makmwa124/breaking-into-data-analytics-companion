# STAR stories worksheet

Write six stories from your current or past work. Each answers a common interview question. Keep each to about 150 words when spoken (one minute).

| # | Question it answers | Situation | Task | Action (what *you* did) | Result (a number if possible) |
|---|---|---|---|---|---|
| 1 | Tell me about a time you used data to make a decision | | | | |
| 2 | Tell me about a time you found an error others missed | | | | |
| 3 | Tell me about a time you explained something complex to a non-expert | | | | |
| 4 | Tell me about a time you handled competing deadlines | | | | |
| 5 | Tell me about a time you disagreed with a manager or stakeholder | | | | |
| 6 | Tell me about a time you learned a new tool quickly | | | | |

Tips
- The Action column is the longest. Say "I", not "we".
- End every story with a result and, if you can, a number: hours saved, errors cut, dollars, customers.
- Rehearse out loud. Time yourself.
